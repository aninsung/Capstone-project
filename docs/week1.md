## 확인과 남은 일

최종 자동 테스트 32개가 모두 통과했다(0.60초). API 인증·9개 작업 계약·String ID·개인정보 오류 비노출·소득 경계·누락·중복·페이지 반복·외부 오류·오래된 원문 차단·키워드 순서 불변성을 확인한다. 실행 명령은 `./scripts/dev.ps1 test`다. Windows 샌드박스 안에서는 이벤트 루프의 로컬 소켓이 차단되어 테스트가 대기했다. 제한 밖에서는 정상 실행됐다. Starlette의 httpx 테스트 클라이언트에 대한 폐기 예정 경고 1건이 있으며 테스트 실패는 아니다.

LLM은 키·모델·제공사가 미설정이다. `data/runs/llm-probe.json`에 NOT_CONFIGURED로 기록했다. 온통청년 키를 LLM 키로 사용하지 않았다. `probe-llm`은 추후 지정한 Chat Completions 호환 API의 연결 확인용이며 실제 호출은 아직 검증하지 못했다.

Backend 담당자와 코드·원문 버전·필수값 합의, 실제 정책의 수동 검토·정답 라벨링은 남아 있다. 분석 엔진·Qdrant·실제 LLM 상담은 2~4주 차 범위다. 따라서 이번 변경은 1주 차 구현 산출물을 제공하지만 계획의 모든 대외 합의·모델 호출 완료를 의미하지 않는다.

## 구현 점검 및 수정 (2026-10-16)

추가 회귀 테스트 6개가 수정 전 모두 실패하는 것을 확인하고 수정했다.

- 정제 파일 쓰기가 실패해도 DB만 갱신되던 문제: 산출물 쓰기까지 DB 트랜잭션에 포함하고 개별 JSON 파일은 임시 파일을 완성한 뒤 교체한다.
- 응답이 인증키를 되돌려주는 경우 페이지 파일만 마스킹되던 문제: 후속 원본·정제본에도 마스킹한 레코드를 전달한다. 모의 응답으로 재현했으며 실제 키 유출을 발견한 것은 아니다.
- 소득 조건 근거가 문서 본문에서 빠지던 문제: 소득 구분·하한·상한 필드를 포함한다.
- 조건 코드와 별도 제한 문구가 함께 있어도 수동 검토가 꺼지던 문제: 예외·추가 조건이 있으면 검토를 요구한다.
- 잘못된 URL 하나 때문에 정상 보조 URL이 있는 정책까지 탈락하던 문제: 잘못된 URL은 건너뛰고 다음 출처를 확인한다.
- 조회수 변화로 같은 페이지의 반복을 놓치던 문제: 정책 ID 집합으로 반복 페이지를 감지한다.

수정 후 전체 38개 테스트 통과(0.79초), 기존 폐기 예정 경고 1건. 실제 원본 재처리 결과 정책 100건·실패 0건, 출처 URL 100개, 조건-문서 근거 연결 600개를 확인했다. OpenAPI 저장 파일과 실행 코드에서 생성한 스키마도 일치했다. 조건 600개 중 447개는 수동 검토 대상이며, 정책 100건 모두 전체 검증은 아직 PENDING_REVIEW다. 이 검사는 정책의 실제 자격 정답이나 출처 웹페이지의 현재 유효성을 검증한 결과가 아니다.

## 임시 실행 테스트 (2026-10-16)

실제 수집본 3건을 임시 폴더에 CLI로 가져온 후 다시 가져와 3건 모두 변경 없음으로 처리되는지 확인했다. 임시 Uvicorn 서버에 실제 HTTP 요청을 보내 health/docs=200, 토큰 누락·무효=401, 입력 오류=400, 계약 미리보기=501을 확인했다. OpenAPI 작업 수는 9개다. 501은 분석 구현 완료를 뜻하지 않는다.

이 과정에서 SQLite 트랜잭션 컨텍스트가 연결 자체를 닫지 않아 Windows 임시 파일 삭제가 실패하는 문제를 발견했다. 연결을 명시적으로 닫도록 수정하고 회귀 테스트를 추가했다. 전체 39개 테스트 통과(0.85초), 폐기 예정 경고 1건. 임시 서버 종료·임시 데이터 삭제·원본 파일 불변을 확인했다. 결과 기록은 `tmp/smoke-result.json`에 있으며 기존 수집 DB는 수정하지 않았다.
